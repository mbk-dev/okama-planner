# План просмотра существующей БД LFP

Спецификация: ../specs/2026-10-11-legacy-viewer-design.md.
Разработка: Python 3.14.4, отдельная ветка legacy-db-viewer публичного Planner; без новых зависимостей.

- [x] RED: синтетическая legacy-БД, реальный HTTP, принадлежность версий/расчётов, неизменность файла, GET-просмотр/отказ POST, ссылки между режимами.
- [x] GREEN: read-only SQLite reader, экранированные таблицы, русские подписи, optional --legacy-database и маршруты существующего защищённого сервера.
- [x] Полный pytest/Ruff, независимое ревью; исправить подтверждённые дефекты.
- [x] Запустить форму с рабочей legacy-БД и новой Planner-БД; открыть просмотр в Orca, проверить только признаки интерфейса/счётчики без личных данных.
- [x] Опубликовать исходники и итог проверки; пакеты PyPI не выпускать.

Приёмка: 692 теста полного набора на Python 3.14.4; независимый HTTP-прогон 22 теста, Ruff чист. В Orca открыт существующий реестр: 7 клиентов, карточка/версии/показатели расчёта рендерятся. Проверены переходы в форму и обратно. Проверка рабочей страницы возвращала только признаки интерфейса и счётчик, без имён/контактов/значений в контексте ИИ. Общий перевод enum ограничен полями перечислений, свободный текст сохраняется. Публикация PyPI не выполняется.
