# План реализации локальной формы клиента

**Цель:** выполнить RS-720 без LLM, сохранить приватность внешнего MCP.
**Спецификация:** ../specs/2026-10-10-local-client-form-design.md.
**Архитектура:** локальный сервер стандартной библиотеки, HTML-форма, доверенный PlannerStore.

- [x] Написать и проверить падающие HTTP-тесты на синтетической БД: создание/изменение, ошибки, повтор, защита Host/Origin/токенов, HTML, версии плана, обезличенное чтение.
- [x] Реализовать `okama_planner.client_form`, локальный запуск и форму без новых зависимостей; провести GREEN и Ruff.
- [x] Документировать запуск, явное создание/выбор БД и границы интерфейса; проверить реальным браузером на синтетических данных.
- [x] Выполнить полный pytest и Ruff, независимое ревью и устранить подтверждённые замечания.
- [x] Зафиксировать фактический результат в RS-720; RS-721 оставить открытой. Публикация нового пакета не входит в задачу.

Ограничения: реальные БД и документы не читать, схему БД и обезличенный MCP-контракт не менять; файлы разработки — отдельная ветка RS-720-local-form. Нет облачных запросов или модели. Исходные несохранённые изменения приватного lfp не затрагивать.

Приёмка: Python 3.14.4; 679 тестов прошли, Ruff чист. Настоящий Chrome: создание, подтверждение, ошибка без потери ввода, изменение, экран 390 px без горизонтального прокручивания, редактор JSON; запросы страницы не загружают внешние ресурсы. PlannerAI выдаёт коды для созданного формой синтетического клиента. Найденные при проверке Origin:null и выбор последней чужой версии исправлены. Скриншот синтетической формы приложен к RS-720. Новые пакеты не выпускаются.
