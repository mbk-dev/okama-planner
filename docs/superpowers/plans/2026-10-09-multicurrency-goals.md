# Реализовать валютные группы целей

Источник: ../specs/2026-10-09-multicurrency-goals-design.md. Общий семейный бюджет подтверждён владельцем. Финансовые изменения проходят TDD; прежние схемы сохраняются.

1. Добавить строгий отдельный MulticurrencyRequest: household (PlanInputs общего бюджета), currency (базовая валюта), groups (ID и полноценный одновалютный joint ForecastRequest), fx (явная модель), contribution_schedule (датированные доли групп), household_funding_order, conversion_fee_rate, seed/mc_number. У каждой группы свой single/per_goal; доход и семейные расходы в группах запрещены для исключения двойного учёта. Проверить общие даты, горизонты, уникальные goal_id, валюты, выравнивание историй и покрытия курса.
2. Подготовить общий куб сценариев по единому индексу исторических месяцев: собственные доходности активов групп плюс изменения курсов. Все курсы положительны; базовый курс равен единице.
3. Добавить координируемый месячный движок. Повторно использовать правила фактического финансирования сегментов, приобретения/продажи имущества, резерва и завершения целей. Семейный бюджет и долг оплачиваются один раз; общий остаток конвертируется и распределяется по группам до их событий. Средства других валют привлекаются на семейный дефицит только по явному порядку. Нативные расходы целей остаются в их группах.
4. Вернуть схему 2.0 с нативными результатами групп, общей оценкой после пересчёта каждой траектории, FX-проводками и общей вероятностью исполнения. Поддержать forecast и сохранение полных запросов/сценариев/результатов с хешами; старые сериализации не менять.
5. Добавить отчёт общего бюджета, горизонтальные денежные потоки валютных групп, валюты целей/стратегий и обмены. HTML/PNG/SVG экспортировать как общую оценку и отдельные графики групп. Локализация через terminology.csv.
6. Вымышленный пример RUB/USD/EUR: общий бюджет, разные режимы групп, расходы, покупки, пенсия, FX. Ручные тесты обмена 1000 RUB → 10 USD при курсе 100, комиссии, недостатка средств, общей корреляции и вероятности; round-trip SQLite; регрессии старых планов.
7. Полный pytest, Ruff, необходимые проверки forecast, пересчёт Excel и визуальная проверка графиков. Независимое ревью финансовых правил и артефактов. Публикация только проверенной работы; новая версия PyPI не входит автоматически в эту задачу.
