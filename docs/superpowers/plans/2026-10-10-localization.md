# RS-712: план завершения локализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** закрыть пропуски локализации существующего пользовательского слоя для en/ru/de/es/zh.
**Architecture:** общий словарь и функции представления в Planner; адаптеры MCP используют явный язык и сохраняют машинные данные.
**Tech Stack:** Python 3.14 для разработки, Poetry, Pydantic, openpyxl, ECharts/Intl, pytest.
**Spec:** docs/superpowers/specs/2026-10-10-localization-design.md.

## Ограничения

Не менять минимальный Python 3.11; не менять финансовые расчёты или реальную БД. Разделять язык и валюту. Не переводить пользовательские имена и названия. Пять языков, английский по умолчанию. Каждый исполнитель пишет в отдельном worktree.

## Проверки рисков

Пустой перевод/дубль/разные placeholders обнаруживаются. Цель с именем из словаря сохраняется. Даты и десятичные суммы различаются только представлением. Формулы Excel с локальными именами листов остаются корректными. Недопустимый язык отклоняется до создания артефакта.
