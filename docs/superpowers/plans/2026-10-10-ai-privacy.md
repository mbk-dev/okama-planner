# Защитить персональные данные на границе ИИ

**Goal:** ИИ работает по кодам; Planner хранит личные данные и сам записывает финансовые версии.
**Spec:** docs/superpowers/specs/2026-10-10-ai-privacy-design.md
**Architecture:** отдельный PlannerAI и обезличенные функции forecast/compare/export; тонкие MCP-адаптеры.
**Tech Stack:** Python 3.14, Pydantic, SQLite/SQLAlchemy, FastMCP, pytest.

## Ограничения и риски

Только синтетические данные. Минимальный Python 3.11 сохраняется. Язык не отменяет защиту. Не возвращать PII в ошибках, примечаниях, дублях, схемах, путях или файлах. Подмена названий сохраняет ссылки replaces_asset/goal_savings_rates/segment_id и финансовые результаты. Старый Planner без безопасного API закрывается по умолчанию. Процессная подпись не заменяет разделение прав файловой системы.
