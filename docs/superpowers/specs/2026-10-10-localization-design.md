# RS-712: завершение локализации okama Planner

Цель: существующие отчёты, графики и локальные клиентские инструменты используют выбранный язык `en` (по умолчанию), `ru`, `de`, `es`, `zh`. Валюта, суммы, календарь событий, JSON/SQL-ключи и тексты пользователя сохраняются.

Общий CSV остаётся источником терминологии. Проверка полноты обнаруживает пустые переводы, дубли и несовпадающие параметры подстановки. Общий слой предоставляет локальные форматы дат и чисел, представления полей реестра и сообщения валидации без утечки значений ввода.

Excel сохраняет числовые ячейки и формулы; язык задаётся форматами отображения, подписи переводятся по роли ячейки. Пользовательские названия целей не переводятся даже при совпадении со словарём. HTML использует Intl с выбранной локалью для сумм, месяцев и подсказок. PNG/SVG наследуют оформление того же HTML.

MCP сохраняет машинные контракты и английский режим по умолчанию, добавляет явный язык вызова и язык описаний при запуске. Переводы клиентского представления отделены от исходной записи. Отдельные изменения MCP не добавляют налоговые модели, новые расчёты или веб-интерфейс.

Документация: матрица покрытия, контракт языка, пять кратких руководств и один воспроизводимый синтетический пример. Проверки используют только искусственные данные. Примеры не требуют сети; HTML и Excel создаются из одного сохранённого результата.
