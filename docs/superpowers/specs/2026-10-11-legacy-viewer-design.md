# Просмотр существующей базы LFP

Запрос владельца: простой локальный интерфейс просмотра заполненной БД LFP со ссылками на форму Planner и обратно.

Один локальный HTTP-сервер поддерживает две поверхности: существующая форма для БД Planner, режим просмотра для отдельно и явно переданной `--legacy-database`. Связующие ссылки доступны в каждом режиме и не копируют/не мигрируют клиентов. В интерфейсе указано, какая база открыта и что просмотр LFP доступен только для чтения.

Просмотр показывает коды клиентов, выбранную карточку, налоговое резидентство, версии входных данных, семью, активы, обязательства, бюджет, цели, портфели, сценарии и сводку сохранённых расчётов. Выбор версии и расчёта проверяет принадлежность клиенту. Не выводить структуру таблиц/SQL или огромный помесячный ledger. Личные сведения отображаются человеку в браузере, не читаются агентом в DOM, скриншотах или логах и не добавляются в MCP.

Соединение LFP открывается с SQLite `mode=ro` и `query_only`; миграций, копирования и записи нет. Сохраняются секрет сеанса, Host/Origin, CSP, отсутствие внешних ресурсов, экранирование, запрет кэширования и диагностических утечек.

Приёмка на синтетической БД: оба перехода, читабельные таблицы, принадлежность версий/расчётов, отказ POST-записи просмотра, отсутствие изменения файла, неизменный интерфейс Planner. Для рабочей базы проверять только наличие элементов и количество клиентов/расчётов без чтения личных значений в контекст ИИ.
